# RowBrief listing and brand package

Five 1600 × 900 JPEG product panels use actual app screens with synthetic examples. `panels.js` records the copy, filenames and accessible descriptions. Raw captures are in `docs/screenshots`; `capture.html?panel=cover`, `dialects`, `findings`, `report` or `preview` reproduces the composition at a 1600 × 900 viewport. Original HTML/CSS/JS and mark SVG remain editable. No paid generation or third-party art was used.

`description.md` is factual marketplace copy. `listing-fields.json` includes seven FAQs, image alt text, requirements and limits. No price or support commitment is invented. This package is prepared separately from publication. No Zero to Hundred listing has been created by preparing these files; the available browser session currently requires sign-in. Verify the correct seller before any edit and leave new consequential agreements or ownership attestations for explicit confirmation.

Original app, artwork, captures, examples and docs use MIT. No third-party fonts or parser dependencies are bundled; preserve LICENSE and THIRD_PARTY_NOTICES.md. Free public repository/tool access does not depend on a marketplace purchase.

The official no-key prefill link is in `prefill-url.txt`. It seeds public title, short copy, demo, repository and category fields; it does not create a listing, set a price, attach source, upload images or accept terms. Remaining long copy, FAQs and images are in this package.

The final focused suite and local browser checks passed; see docs/verification.md. Public GitHub/demo publication is verified separately in the release record. This package remains prepared for Zero to Hundred, with no marketplace fields saved or published.

# RowBrief design

A file handoff workbench for operations and data recipients. The main visual idea is a record grid with one mint location marker. Color: cobalt #3547BE for actions, ink #202B3B for reading, mist #EEF2FD for the input bench, mint #BEE5DE for the handoff area, amber #805409 for review, white #FFFFFF. Trebuchet MS is the preferred installed system face, with Segoe UI and sans-serif fallbacks. No font files are distributed.

The layout places the stable source and parsing choices on the left and evidence on the right. On phones the source precedes results. Labels explain choices without automatic guessing. Tables scroll inside their own region; the page remains narrow. Findings point to one-based physical source locations. Reports visually separate sharing metadata from private cell preview. No decorative animation or implied results.

Before implementation, the initial generic dashboard-card approach was rejected in favor of a single continuous input/results bench, a compact grid mark and the actual CSV workflow. Original artwork and design use MIT. Screenshots use synthetic data.
